# AI 每日对话启动器

可直接打开的中文单文件网页，用每日十个方向练习独立思考，并通过批判性提问减少对话中的迎合。

## 使用

下载 `index.html` 后用浏览器打开；或解压 `ai-daily-dialogue-release.zip`，打开其中的 `index.html`。

- 十类对话方向，每类五条问题，支持轮换、随机和自定义编辑。
- 五维认知能力概览与每日进度记录。
- 可填写自己的初步判断，随问题一起复制。
- 批判性提问优化：前提检查、反证、替代解释、证据质量与持续纠错。
- 提供“对话中途校准”提示词。
- 支持手机和桌面布局。

网页在本地组合提示词，未调用 AI API。复制问题后，可打开 ChatGPT 粘贴发送。提示词不能保证 AI 始终保持独立判断。

## 数据保存

进度与编辑内容仅保存在当前浏览器的本地存储中，按设备日期切换；不会上传到此仓库，也不会跨设备同步。更换网址、浏览器、文件位置或清除浏览器数据可能导致原记录不可读取。

## 网站托管

将 `index.html` 上传到静态网站托管平台即可。发布 ZIP 的根目录包含 `index.html`，可用于支持直接上传的托管平台。

上传到 GitHub 仓库与启用网站托管是两个步骤；仓库本身不会自动成为可打开的网页。若使用 GitHub Pages，需要另行指定发布分支和目录。

## 内容

十类方向和五维框架依据设计时提供的原始对话。每类第一题保留原始提问，其余四题为扩展训练示例。能力概览显示练习覆盖情况，不是实际能力评分。
